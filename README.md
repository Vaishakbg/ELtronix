# Eltronix

A modern B2B electronics ecommerce platform built with WordPress, WooCommerce, and modern frontend technologies.

## Tech Stack

- WordPress
- WooCommerce
- PHP 8+
- Tailwind CSS
- Vite
- Alpine.js
- Git
- GitHub
- GitHub Copilot

## Project Structure

- themes/eltronix-theme
- plugins/eltronix-core

## Goals

- Premium UI/UX
- Enterprise-grade architecture
- Mobile-first
- High performance
- Accessible
- Secure
